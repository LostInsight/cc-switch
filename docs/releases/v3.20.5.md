# CC Switch v3.20.5

发行说明日期：2026-09-11

本版本汇总本地定制分支的模型路由、HTTP 错误处理、持续重试及 WSL2 工作流修复。

## 主要更新

- 修复复用供应商编辑表单时残留旧 Codex 模型映射的问题。支持将请求模型 `gpt-5.6-sol` 映射到上游 `gpt-6-astra`。
- 失败请求日志分别记录原始请求模型与映射后的上游模型，避免把日志中的别名误认为实际出站模型。
- HTTP 状态覆盖在未开启跨供应商故障转移时同样生效：继续尝试（Retryable）按配置重试当前供应商，透传错误（Non-retryable）立即返回错误。可对 400、405 等状态单独配置。
- 新增可选的持续重试模式，用于继续尝试 Retryable 错误，直到成功或客户端取消；供应商熔断时等待恢复探测窗口，不将永久配置错误当作可重试故障。
- 更新简体中文、繁体中文、英文和日文的错误处理说明。
- 修复 WSL2 Nightly 的编译/执行隔离：使用原生 Windows 临时目录编译全部测试，在 WSL2 目录下直接执行测试程序，保留单元测试和集成测试覆盖。

## 升级提示

- 升级前建议备份现有 CC Switch 数据目录；数据库结构会从 v18 自动升级到 v19。
- 持续重试默认关闭，已有配置继续使用有限重试次数。
- “继续尝试”仍受有限重试次数或持续重试开关约束；未开启故障转移时不会切换到其他供应商。
- 发行说明日期按项目要求标注为 2026-09-11，GitHub 实际发布时间以平台记录为准。
